# Geliştirici Kiti Kurulumu

Yazılım geliştirme ve yapay zeka projelerine başlarken bilgisayarınızda bulunması önerilen temel araçlar.

## 1. Temel Geliştirici Araçları
* **Git:** Versiyon kontrolü için [git-scm.com](https://git-scm.com/) üzerinden kurulum.
* **VS Code:** Kod editörü ve önerilen temel eklentiler (Python, C/C++, GitLens).

## 2. Python Ortamı
* Python 3.10+ kurulumu ve `PATH` ortam değişkeninin eklenmesi.
* Sanal ortam (`venv` veya `conda`) oluşturma pratiği.

```bash
# Örnek sanal ortam kurulumu
python -m venv venv

# Windows (PowerShell / CMD) için aktivasyon:
.\venv\Scripts\activate
```

> *Not: İlerleyen adımlarda C/C++ derleyici kurulumu ve yaygın veri bilimi kütüphaneleri (OpenCV, PyTorch) rehbere eklenecektir.*
