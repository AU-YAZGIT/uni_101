# Visual Studio Code Kurulum Rehberi

Visual Studio Code (VS Code), yazılım geliştirme projelerinde en yaygın kullanılan açık kaynaklı, hafif ve güçlü kod editörüdür.

---

## 1. Kurulum Adımları

1. [code.visualstudio.com](https://code.visualstudio.com/) adresine gidin.
2. İşletim sisteminize uygun (Windows / macOS / Linux) yükleyiciyi indirin.
3. Kurulum sihirbazını başlatın.

> **Windows için Önemli Ayar:**  
> Kurulum ekranındaki **"Ek Görevleri Seçin" (Select Additional Tasks)** adımında şu iki seçeneği mutlaka işaretleyin:  
> * **"Add 'Open with Code' action to Windows Explorer file context menu"**  
> * **"Add 'Open with Code' action to Windows Explorer directory context menu"**  
> Bu sayede bilgisayarınızdaki herhangi bir klasöre veya dosyaya sağ tıklayıp tek hamlede *"Code ile Aç"* diyebilirsiniz.

---

## 2. İlk Ayarlar ve Temel Arayüz

* **Türkçe Dil Paketi:** Editörü Türkçe kullanmak isterseniz sol taraftaki eklentiler menüsünden (`Ctrl + Shift + X`) **Turkish Language Pack for Visual Studio Code** eklentisini kurabilirsiniz.
* **Entegre Terminal:** Üst menüden `Terminal -> New Terminal` seçeneğiyle veya klavyeden ``Ctrl + ` `` kısayolunu kullanarak VS Code içinden ayrılmadan terminal açabilirsiniz.

---

## 3. Genel Geliştirici Eklentileri

* **GitLens:** Git geçmişini ve kod satırlarının kime ait olduğunu gösterir.
* **Material Icon Theme:** Dosya ve klasör simgelerini renklendirerek proje hiyerarşisini belirginleştirir.
* **Prettier - Code Formatter:** Kodlarınızı kaydederken otomatik olarak hizalar ve temizler.
